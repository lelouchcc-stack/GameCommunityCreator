# 项目介绍

项目面向对象：开发者

项目背景：近年来AI的发展，小团队的游戏数量暴增，但是这些游戏没有属于自己的社区讨论地方，玩家只能在贴吧、nga、discord、qq等社区聊天。本项目的目的是创建一个可以开箱即用的“类米游社”web项目，游戏团队只需要修改一些属于自己游戏的设计风格即可构建。


## 项目开发背景

近年来，中国游戏产业持续保持高速增长，游戏已经从单纯的娱乐方式演变为一种重要的数字文化载体。中国游戏用户规模已超过6亿,年轻玩家群体不仅追求游戏本身的品质，更渴望在游戏之外找到同好交流、内容分享和情感共鸣的阵地。在这一背景下，游戏垂直社区的价值日益凸显。
以米哈游旗下的“米游社”和库洛游戏旗下的“库街区”为代表，游戏厂商官方社区平台通过聚合游戏资讯、玩家攻略、二创内容、互动讨论等功能，成功构建了高粘性的玩家生态。这类平台不仅是玩家获取信息和交流的场所，更是游戏厂商进行用户运营、内容分发和品牌建设的重要工具。
然而，目前市场上主流的综合型社区平台（如贴吧、微博、B站等）虽然拥有庞大的用户基数，但内容过于泛化，游戏玩家难以在其中获得聚焦、纯粹的交流体验。而独立游戏开发者或中小型游戏团队，又往往缺乏技术和资源去搭建属于自己的垂直社区。因此，设计并实现一个面向游戏玩家的垂直社区平台，具有明确的现实需求和实用价值。

## 系统开发目的	

降低独立游戏团队的社区建设成本与门槛：提供可直接部署上线的完整社区产品，团队无需投入开发资源自建社区。实现零代码配置上线：管理者通过管理端配置站点信息、主题外观、首页模块、板块与内容维度即可完成社区个性化；配置与代码分离，不影响系统后续升级。解决通用论坛与游戏内容组织不适配的问题：以"游戏版本"与"玩家进度阶段"两个维度组织内容，让攻略在正确的版本、正确的进度下被正确的人看到。保障社区内容可控：通过 RBAC 权限体系、帖子审核、举报处理与操作日志，实现内容可管可控、操作可追溯。
具体而言，本系统参考米游社、库街区等成熟游戏社区的产品模式，以“游戏分区”为核心组织内容，以“用户发帖与互动”为主要交互方式，辅以后台管理功能，构建一个从内容生产、内容消费到内容审核的完整闭环。通过本系统，玩家可以快速找到自己感兴趣的游戏分区，浏览攻略、二创、讨论等帖子，并进行点赞、收藏、评论回复等互动；管理员可以对帖子、评论、用户和游戏分区进行统一管理，保证社区内容健康有序。

## 功能需求分析
用户端功能需求
用户端主要面向普通玩家，功能模块如下：
(1)登录注册: 注册、登录、退出、登录态保持、未登录拦截
(2)个人主页:
(3)板块浏览
(4)攻略发布
(5)攻略浏览与检索
(6)评论互动
(7)举报
管理后台面向管理员，功能模块如下：
(1)用户管理
(2)角色管理
(3)菜单管理
(4)操作日志
(5)站点配置
(6)板块管理
(7)内容维度配置
(8)帖子审核与举报处理
(9)数据统计
